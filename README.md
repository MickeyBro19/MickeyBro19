## 🚧 What I'm Building

### 🎬 CineBook

> **A production-style movie ticket booking backend built with Spring Boot.**

This is currently my main project and my playground for learning how real backend systems are designed.

**What's inside:**

* 🔐 JWT authentication + refresh tokens
* 🍪 Secure HTTP-only cookie handling
* 👤 User authentication & authorization
* 🎥 Movie, screen and show management
* 💺 Seat management
* 🎟️ Booking workflows
* 💰 Booking amount calculation
* 🔄 Transactional operations
* 🔎 Search, filtering, pagination & sorting
* ⚠️ Global exception handling
* ✅ Validation & business-rule enforcement
* 🧪 Unit testing with JUnit & Mockito
* 🗃️ PostgreSQL + JPA/Hibernate

**Stack**

`Java` `Spring Boot` `Spring Security` `PostgreSQL` `JPA` `Hibernate` `JWT` `JUnit` `Mockito`
